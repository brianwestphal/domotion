Domotion capture from DM-1503. `wikipedia-fidelity.png` is the public derivative.

```bash
node site/scripts/generate-fidelity-proof.mjs
```

renderings closely match in the recorded macOS Chromium environment, while
consumer antialiasing and hinting may vary by platform. The generator replaces
