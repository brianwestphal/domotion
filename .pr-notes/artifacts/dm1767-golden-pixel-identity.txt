Both examples changed shape only because DM-1767 removed `overlays` from the
autoCompress exclusion set. editor-session is the flagship: its five typed-line
frames (each carrying a `typing` overlay with `holdToFrameEnd: true`) collapse
into one compressed run, and the overlays ride along as per-state overlays.
`holdToFrameEnd` now cuts at the overlay's WINDOW end, which for a per-state
overlay is its state's end — the same instant the member frame's own cut was, so
the hard handoff to the next state's real page text is preserved.

Frame 7's line stays a plain sibling frame because frame 8 carries `textTracks`,
which is still a blocker; frames 6 and 9 were already authored `states` runs.
